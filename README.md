# sistema-de-Gerenciamento-de-Veículos
Um sistema de gerenciamento de alugueis de veículos.
É capaz cadastrar diferentes tipos de veículos (no código), exibir suas informações e calcular o valor de um aluguel diário conforme o tipo de veículo. Cada tipo possui sua própria regra de cálculo.
Nesse projeto eu mexi com classes abstratas, classes concretas, herança, polimorfismo e refinei a interação com o usuário (permitindo ele fazer mais de um cálculo sem o programa encerrar).
